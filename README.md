# Wonderbox
After waking up in a mysterious tower, you find yourself with the no memories and no way out.  Brave the levels of the tower and find your way up. On the way, recover the memories you once lost and discover who you are.

This game has 10 levels, 3+ unique puzzles per level, and 3 boss fights! 



This game is the Alpha version - some features lack polish will be updated in the next version. In the meantime, please let us know where we can improve!

The attached files are for the game code, including some that may be outdated or unused due to changes in game design. The save/load system is planned to be used in future updates, but is currently not enabled in game.
